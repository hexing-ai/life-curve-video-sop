# 把一个人的一生，画成一条曲线

**Vibe 知识打赏 · 人生曲线视频制作 SOP**

给 AI 一个人物名字和一首背景音乐，让它先交一份可以逐秒审阅的剧情脚本。你确认后，再把脚本做成一条无旁白的人物短片。屏幕上的发光折线跟着人物的际遇涨跌，每个拐点配上年份、事件和一张相关照片。最后镜头拉远，观众能看见前面每一次起落在整段人生中的位置。

[阅读完整制作 SOP](./人生曲线视频_制作SOP.md)

## 一个转折，怎样变成画面？

SOP 里的一个脚本示例写到乔布斯 30 岁离开自己创办的公司。在时间轴上，这件事被安排在 **16.00–17.77 秒**。背景切到公司大楼，画面标出「1985 · 30 岁」，红色曲线在镲片响起时深跌，左下角的打击计数加一。不到两秒，观众就能看懂他失去了什么。这里的「人生指数」由创作者根据剧情设定，用涨跌表现事件的分量。

## 谁适合用？

- **做人物故事的短视频创作者**可以直接用第二、三章选事件、写开头、排节奏。先从人物几次低谷里找出反复出现的冲突，再决定哪些成就值得讲。
- **和 AI 协作的创作者**可以用逐秒时间轴审稿。渲染前就能判断开头的悬念在哪一秒揭晓、哪句字幕来不及读、哪张背景图需要换。
- **想持续更新人物系列的人**可以按第四章搭建渲染流程。第一期跑通后，后续各期可沿用镜头、字幕和音效规则，更换人物时间轴、音乐与图片。

## 第一次怎么用？

1. 准备人物名字和一首 MP3。建议选 **60–75 秒**的音乐，成片与音乐等长。
2. 把完整 SOP 和 MP3 一起交给能读取音频的 AI。可以这样开场：

   > 人物是乔布斯，背景音乐见附件。请按这份 SOP 先分析音乐，再交剧情主线、开场两句话和逐秒时间轴。请标出每条人物事实的来源类型，等我确认脚本后再制作。

3. 审脚本时，先看开头提出的危机有没有在后面得到回应，再核对年份、数字和引语。时间轴每行都应写清事件、曲线动作、背景图、特效和音乐点，可以直接按秒提出修改。
4. 确认脚本后，在可运行 Python 和 FFmpeg 的环境中按第四章制作。先查看 15–20 张关键帧拼成的总表，检查字幕、图片和曲线的位置，再渲染全片，抽检音乐高潮处的画面。

## 制作完成后会拿到什么？

| 交付物 | 用途 |
| --- | --- |
| 1920 × 1080、30 fps 横屏 MP4（H.264 + AAC） | 播放成片。声音由背景音乐和合成音效组成，全片无旁白。 |
| 关键帧总表 | 一眼检查片头、低谷、反转、巅峰和片尾的画面。 |
| 事实核对说明 | 标出使用了约数或仍需确认的细节，方便发布前复核。 |

## 仓库内容与制作环境

本仓库提供完整的 Markdown 制作规范。文中列出的 `timeline.py`、`render.py`、`sfx.py` 和 `run.sh` 是搭建制作项目时要实现的文件。音乐、人物图片与参考片由制作时准备。只做选题和脚本，可以直接从第二章开始。

完整渲染流程使用 Python、librosa、NumPy、OpenCV、Pillow 和 FFmpeg。SOP 给出的字体位置适用于 macOS，其他系统需换成本机可用的中西文字体。参考视频路径也请换成你自己的文件位置。
